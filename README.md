# Weather Forecast Service (Сервис получения метеорологических данных)

Консольное Java-приложение для получения фактической погоды и прогноза через REST API **Яндекс Погоды v2** (`/v2/forecast`), извлечения текущей температуры и расчета средней дневной температуры за заданное количество суток.

Проект разработан в рамках практического задания с применением принципов ООП, разделением на интерфейсы и реализации, а также покрытием бизнес-логики модульными тестами на **JUnit 5**.

---

## Функциональность

* Выполнение GET-запроса к эндпоинту `https://yandex.ru` с передачей координат (`lat`, `lon`), количества суток (`limit`) и заголовка авторизации `X-Yandex-Weather-Key`.
* Вывод полного необработанного JSON-ответа от сервиса в консоль «как есть».
* Безопасный парсинг JSON с помощью **Jackson** и извлечение текущей температуры (`fact.temp`).
* Расчет среднего арифметического значения дневной температуры (`forecasts[*].parts.day.temp_avg`) за первые `limit` суток прогноза.

## Требования и запуск

### Системные требования
* **JDK 17** или выше
* **Apache Maven 3.8+**

### Настройка API-ключа и запуск
1. Клонируйте репозиторий и перейдите в директорию проекта:
   ```bash
   git clone https://github.com
   cd java_second
   ```
2. Получите ключ доступа в кабинете [Яндекс Погода для бизнеса](https://yandex.ru) (тариф с поддержкой REST API v2 `/v2/forecast`).
3. Задайте ключ через переменную окружения `YANDEX_WEATHER_KEY` (в терминале или в настройках Run Configuration в IntelliJ IDEA):
   ```bash
   export YANDEX_WEATHER_KEY="ваш_активный_ключ_api"
   ```
4. Соберите и запустите приложение:
   ```bash
   mvn clean compile exec:java -Dexec.mainClass="ru.my.corp.weather.Main"
   ```

### Пример вывода в консоль
```text
=== Полный ответ сервиса (JSON) ===
{"now":1795277040,"now_dt":"2026-11-21T16:24:00.000Z", ...}

=== Текущая погода ===
Текущая температура (fact.temp): 2 °C

=== Прогноз погоды ===
Средняя дневная температура за 5 сут.: 1.20 °C
```

## Тестирование

Для проверки корректности парсинга JSON, математических расчетов и обработки граничных случаев (без расходования лимитов API-ключа) реализованы модульные тесты с использованием заглушки `StubWeatherClient`.

Запуск всех тестов через Maven:
```bash
mvn test
```

### Покрытые тестовые сценарии (`WeatherServiceTest`)
* Корректное извлечение `fact.temp` и расчет средней дневной температуры за `5` суток.
* Расчет средней температуры при частичной выборке по параметру `limit` (например, `3` суток из `5`).
* Корректная обработка ситуации, когда запрошенный `limit` превышает количество дней в ответе сервера.
* Выброс исключений при некорректном параметре `limit <= 0`, отсутствии поля `fact.temp` или невалидном JSON.
